# 知识库问答评测

衡量知识库问答两件事：**检索**能否找到回答所需的条款，**回答**是否基于这些条款并正确引用。数据集是 `questions.jsonl`，共 89 道题，覆盖 5 份示例规则。

## 运行

```bash
pnpm eval:kb                                        # 离线检索评测：全部离线配置，不需要 API Key
pnpm eval:kb --variants baseline,rewrite            # 指定配置；rewrite 需要模型密钥
pnpm eval:kb --variants hybrid                      # 需要先 pnpm kb:ingest --embed，且服务器有向量模型密钥
pnpm eval:kb --mode answer --provider deepseek --model deepseek-v4-flash   # 端到端回答评测
pnpm eval:kb --filter paraphrase,followup           # 只跑部分类别或题号前缀
```

模型密钥从 `.env` 读取（与应用相同的服务器配置）。结果写入 `results/`，包括 JSON 明细和 Markdown 汇总；需要保留的基线命名为 `baseline-*`。

## 题目格式

```json
{"id":"multi-02","category":"multi","question":"辅助服务市场和现货市场是联合出清还是分开出清？",
 "gold":[["ancillary-service-market-2025:第四十四条"],["spot-market-2023:第六十四条"]]}
```

- `gold` 中的每个数组是一个**要点**，完整回答需要覆盖所有要点。数组里的几条是同一要点的**可互换来源**，命中其中任意一条即可。条款写作 `文件ID:第X条`，名词解释写作 `文件ID:名词解释N`。
- 标准答案标注的是条款，不是切块，所以改变切块方式后结果依然可比。
- `followup` 题带有 `history`，用来测试问题改写能否补全指代。离线检索只用原问题，因此这类题主要用来对比 `rewrite` 配置。
- `out_of_scope` 题的 `gold` 为空，这类题检索结果应为空，回答应拒答。

| 类别 | 题数 | 考察点 |
|---|---|---|
| lookup | 27 | 问法接近原文的条款查询 |
| definition | 14 | 名词、概念解释 |
| paraphrase | 18 | 口语化提问，用词和原文不同（考验语义检索） |
| multi | 10 | 需要多个要点，常常跨文件 |
| validity | 5 | 施行、到期、废止 |
| followup | 5 | 需要结合上文理解的追问 |
| out_of_scope | 10 | 知识库外的问题 |

**标注说明**：题目和标准答案由 Claude 根据规则原文编写，每个标准条款都核对过原文。但没有经过领域专家审核，建议上线前请业务人员抽查。`tests/knowledge-eval.test.ts` 会检查每个标注的条款都真实存在。

## 指标

**检索**（取前 10 条）：

| 指标 | 含义 |
|---|---|
| Hit@k | 前 k 条中至少命中一个要点 |
| Recall@k | 前 k 条覆盖的要点比例 |
| 完整@k | 前 k 条覆盖全部要点 |
| MRR | 第一条命中结果排名的倒数，取平均 |
| 库内空检索 ↓ | 有答案的问题却什么都没检索到 |
| 库外空检索 ↑ | 库外问题正确地检索为空 |

**回答**（`--mode answer`，仅知识库模式、标准回答长度）：

| 指标 | 含义 |
|---|---|
| 回答率 | 库内问题没有被拒答 |
| 引用有效率 | 引用校验通过，且至少有一处引用 |
| 引用准确率 | 被引用的条款中，属于标准答案的比例 |
| 要点覆盖率 | 回答引用到的要点比例 |
| 库外拒答率 | 库外问题被正确拒答 |
| 延迟、模型调用次数 | 性能与成本参考 |

目前还没有"用另一个模型判卷"的忠实度评分，引用准确率只能间接反映回答是否有依据。

## 当前基线（离线，仅关键词检索）

见 `results/baseline-retrieval.md`。主要结论：

- **门槛**：相关性门槛改为"覆盖率 ≥ 0.2，或命中词 IDF 总和 ≥ 6"后，库内 Hit@5 从 79.7% 提升到 89.9%，库内空检索从 17.7% 降到 6.3%，库外空检索保持 90%。不设门槛时，库外问题只有 20% 能检索为空。
- **短板**：口语化题 Hit@5 只有 66.7%，追问题只有 60%。这正是向量检索和问题改写要解决的，可以用 `hybrid`、`rewrite` 配置验证。
- **其他消融**：只用 ICU 分词时，库外误检明显增多。去掉章节路径前缀后，Hit@1 和 MRR 下降。切块大小在这个语料上影响不大。

**注意**：门槛是在这份评测集上调出来的，同一份数据上的数字偏乐观。要得到无偏的结论，需要另外准备一批没参与调参的新题。
